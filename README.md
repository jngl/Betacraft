# Betacraft

A voxel survival and building game inspired by Minecraft: one player exploring, surviving and building in procedurally generated worlds. Written in C++20 with OpenGL 3.3 Core, SDL2 and miniaudio. Every texture and sound is generated by the game at startup; it ships no third-party game assets.

## Features

- **Procedural worlds (`worldgen`)**:
  - A temperature × humidity climate map with 10 biomes (`Rainforest`, `Seasonal Forest`, `Forest`, `Taiga`, `Savanna`, `Shrubland`, `Plains`, `Swampland`, `Desert`, `Tundra`) and per-column grass and foliage tints.
  - 3D terrain with overhangs and cliffs, sand/gravel/clay beaches at sea level (`Y = 64`), carved caves and ore veins (coal, iron, gold, diamond, redstone, lapis lazuli).
  - Oak, birch and pine trees, tall grass, flowers, cacti and sugar cane.
- **Lighting and rendering (`render`, `streaming`, `lighting`)**:
  - Smooth lighting: per-vertex ambient occlusion with interpolated sky light and block light (`0..15`), plus dynamic light from held and dropped torches.
  - Day/night cycle with sun, moon, stars, cubic clouds at `Y = 108`, fog, rain and lightning.
  - Two-pass rendering (opaque/cutout, then translucent water and ice), frustum culling, and chunk meshing on worker threads.
  - Mining cracks in 10 stages, block-break particles, and a first-person hand/tool/block with view bobbing.
- **Simulation**:
  - Water and lava that flow as a cellular automaton (`fluids`).
  - Redstone wire, torches, levers, buttons and pressure plates (`redstone`), pistons.
  - Passive and hostile mobs (pig, cow, sheep, zombie, skeleton, spider, creeper) with A* pathfinding (`ai`).
- **Survival (`gameplay`, `crafting`, `physics`)**:
  - Per-axis AABB collisions, gravity, swimming, and sneaking that stops you at ledges.
  - Health (10 hearts) with fall damage, drowning and combat; armor, food, tools that wear out.
  - 36-slot inventory, 2×2 and 3×3 crafting, furnaces and chests.
  - Survival and creative modes; creative unlocks flying, the block palette and time skip.
- **Procedural audio (`audio`, `acoustics`)**:
  - Real-time polyphonic synthesis: footsteps, mining, breaking and placing per material, water splashes, pistons, UI clicks, and ambient music (toggle with `M`).
  - Sound occlusion and room reverb computed from the surrounding blocks.
- **Self-contained assets (`render/TextureAtlas`)**:
  - Generates a 16×16 pixel-art atlas (`256×256` RGBA) at startup and exports it to `assets/terrain.png`; a custom `assets/terrain.png` replaces it (both need libpng).
- **Saves (`storage`)**:
  - Region files (`region/r.X.Z.bcr`) with zstd-compressed chunks, a text `level.dat`, autosave and manual save (`F5`). Saves are written atomically, and a save from a newer version is never overwritten.

## Controls

| Key / mouse | Action |
|---|---|
| `W/A/S/D` or `Z/Q/S/D` | Move (QWERTY and AZERTY) |
| `Space` | Jump / swim / fly up |
| `Left Shift` | Sneak (stops you at ledges) / fly down |
| `Left Ctrl` | Sprint |
| `Left click` (hold) | Mine / attack |
| `Right click` | Use: place a block, open a crafting table, furnace or chest, eat… |
| `Middle click` | Pick block into the hotbar |
| `1..9` or mouse wheel | Select a hotbar slot |
| `E` or `I` | Open/close the inventory and crafting (and the block palette in creative) |
| `F` | Toggle flying (creative) |
| `T` | Skip time forward (creative) |
| `L` | Toggle smooth lighting |
| `M` | Toggle ambient music |
| `F3` | Show/hide the debug screen |
| `F5` | Save the world |
| `F11` | Toggle fullscreen |
| `Esc` | Release the mouse / close the inventory / quit (autosaves) |

## Build and test

Needs a C++20 compiler, CMake and SDL2 (found through pkg-config). libzstd and libpng are optional (`-DBETACRAFT_WITH_ZSTD=OFF`, `-DBETACRAFT_WITH_PNG=OFF`).

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure -LE benchmark
./build/betacraft                       # pick or create a world on the title screen
./build/betacraft --gamemode creative   # new worlds start in creative mode
./build/betacraft --help                # all command-line options
```
